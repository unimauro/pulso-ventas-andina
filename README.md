# Pulso de Ventas · Distribuidora Andina

Dashboard de ventas 2025 de **Distribuidora Andina** (empresa ficticia).

🔗 **Live:** https://unimauro.github.io/pulso-ventas-andina/

- Titular con el hallazgo del año + tarjetas con semáforo (ventas, margen, pedidos, vencido).
- Gráficos por mes, región, canal y top 5 productos.
- Filtros en vivo por mes, región, canal y vendedor.
- Alertas automáticas (más descuento, lo que crece, lo que cae) y 3 acciones para el gerente.
- Cálido y profesional, en español, montos en S/, responsive y modo oscuro.

Hecho solo con datos de `ventas-2025.json`. Página estática, sin dependencias externas.
